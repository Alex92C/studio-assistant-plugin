# Packages

`search_packages` with `kind: "catalog"` lists packs the studio sells. `kind: "active"` lists packs currently assigned to one person. Pass that person's `userId`.

Granting a pack is not a plugin tool yet. If the user asks to grant or remove a pack, say that this assistant cannot do that from the plugin and that they can do it in the studio app.
